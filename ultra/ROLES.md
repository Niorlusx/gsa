# Roles

| Role | Does | Does not |
|---|---|---|
| Lead | Chooses the smallest action, writes the file, stops | Expand scope mid-run |
| Operator | Eight-verb surface, plain language | Bypass policy |
| Reviewer | Failure mode and one recovery path | Silent retry loops |
| State | Layout and state files | Secrets in files |
