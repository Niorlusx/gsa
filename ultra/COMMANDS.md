# Commands

```
python3 ultra/desk.py status
python3 ultra/desk.py plan "ship the operator card"
python3 ultra/desk.py ask "what is blocked"
python3 ultra/desk.py build "one-page brief"
python3 ultra/desk.py review ultra/BRIEF.md
python3 ultra/desk.py save operator-card
python3 ultra/desk.py search "local note only"
python3 ultra/desk.py next
```

| Verb | What it does |
|---|---|
| status | Open jobs, last output, disk check |
| plan | Break a goal into steps and assign roles |
| ask | Record a question for the team lead to answer |
| build | Write a spec into outputs/ and mark the job done |
| review | Read a file and write a short critique |
| save | Snapshot session.json |
| search | Store a search topic; web search stays with the lead |
| next | Print the oldest open job |

One verb per run.
